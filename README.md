# salesrp-frontend-dist

セールスロープレの OTA バンドルの配信先。

**中身は CI が自動生成します。手で編集しないでください。**
`salesrp-frontend` の `ota-deploy` ワークフローが、Ed25519 で署名した zip と
その署名、および各系列の最新版を指す `version_info-<x.y>.json` を置きます。

アプリは適用前に必ず署名を検証します。検証に落ちたバンドルは適用されません。

**シナリオもこのバンドルに入ります。** シナリオを足したり直したりしたぶんは、
アプリの更新として同じ経路で配られます。シナリオ専用の配信経路は作りません。
